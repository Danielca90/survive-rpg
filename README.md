# Survive RPG

Juego de supervivencia sandbox 2D en vista lateral, en un solo archivo HTML (canvas, sin dependencias).
Pensado para iPhone en horizontal; también funciona en iPad y Mac.

## Jugar
Abre `index.html` en el navegador, o sírvelo localmente:

```bash
python3 -m http.server
```

## Características
- Mundo infinito por chunks con generación por semilla: desierto, pradera, bosque, montaña y nieve.
- Minería, construcción, herramientas con niveles y durabilidad, menas de cobre, oro y diamante.
- Zombis que rompen paredes, arañas que trepan y hordas nocturnas.
- XP, niveles, habilidades y mobs con nivel.
- Refugio con NPC, despensa, economía diaria, mejoras y 15 misiones.
- Controles táctiles y de teclado; guardado local (localStorage).
